# Gate 2 — five observed manual API cases (2026-10-04)

## Scope and method

Five **human-authored probes** were sent to the actual FastAPI app and their responses manually inspected. A short local script repeated the HTTP actions consistently; this was not a mocked unit test. OpenRouter chat and `openai/text-embedding-3-small` embeddings were used. The run used `origin/develop` commit `0e57d8b`, `SCENARIO_01_VF5_TAXI`, the tracked knowledge corpus, and **temporary isolated SQLite/Chroma stores**. Two synthetic demo accounts were created for the run. The API key was loaded from a local ignored `.env`, never printed or committed. Requests were made through `httpx.ASGITransport` with actual app lifespan, so this verifies backend → agent/provider → storage → API, **not** the browser UI or a deployed URL. The five cases below are not five full scenario attempts and are not a 50-case golden-dataset result.

## Limits and follow-up

- A **separate headless Chromium smoke** used the same `develop` source with isolated servers (backend `8017`, frontend `3017`) and synthetic accounts. Visible flow and HTTP observations: Advisor login → Copilot VF 8 answer visible (`query` **200**) → Role-play turn (`message` **200**) → finish (`finish` **200**) → scorecard visibly showed **1.25/3**, four assessed skills and transcript quotes → Manager opened that draft and approved (`PATCH /manager/reviews/{id}` **200**). The lower browser score comes from a **different one-turn attempt**, not the three-turn G2-03 attempt scored 2.0/3. No browser page error was reported by the script, but this was a smoke, not a comprehensive usability study. Browser screenshots were inspected locally and not committed.
- Separate deterministic checks on this checkout: Python 3.12 `pytest tests -q` **174 passed**; `ruff check src tests` and `ruff format --check src tests` passed; frontend `npm run lint` and Vite build to a temporary output directory passed. Python 3.11 and GitHub Actions were not run in this checkout.
- These are five **cases in one local run**, not five independent role-play sessions. They satisfy the requested minimal Gate 2 manual evidence only if the course accepts backend/API observation; record a browser video separately.
- Citation resolvability was checked; human verification that every clause is supported, expert agreement for the judge, browser E2E, backend restart and hosted persistence were **not** measured by this run.
- The wider [Copilot benchmark](../datasets/copilot_benchmark.json) contains 50 authored cases, but this report does **not** claim it was executed live. Do not label this output “golden dataset accuracy” or a calibrated judge score.
- If the final `develop` commit changes after `0e57d8b`, rerun these five cases or state the commit difference in the submission.
